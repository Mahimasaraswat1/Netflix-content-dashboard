# 🎬 Netflix Content Intelligence Dashboard

An interactive Netflix analytics dashboard built using Python, SQL, and Tableau to analyze content trends, ratings, genres, and country-wise distribution.

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- SQL
- Tableau
- Matplotlib

---

## 📊 Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Interactive Tableau Dashboard
- Genre Analysis
- Ratings Analysis
- Country-wise Insights
- Content Trend Visualization
- Movies vs TV Shows Comparison

---

## 📈 Key Insights

- Movies dominate Netflix content library
- USA contributes the highest amount of content
- TV-MA is the most common rating
- Netflix content rapidly increased after 2015
- Drama and Comedy are the most common genres
